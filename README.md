# Port Nova

A 3D open-world driving game built with Three.js — drive around, pick up passengers, manage money and health, and explore. Built as a passion project.

[![Play Port Nova](https://img.shields.io/badge/▶%20Play-Port%20Nova-8fe04a?style=for-the-badge)](https://olexat.github.io/port-nova/)

## Controls

- **WASD / Arrow keys** — move
- **Shift** — run
- **F** — get in / out of a car
- **Space** — handbrake
- **H** — horn
- **T** — manual / automatic transmission
- **Q / E** — shift gears
- **X** — drift
- **K** — map
- **Mouse drag** — camera

## Running locally

Just open `index.html` in a browser — no build step, no dependencies to install. It loads Three.js from a CDN.
